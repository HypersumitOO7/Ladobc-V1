# Ladobc — First Playable Prototype

This package contains the early browser-playable Ladobc fighting-game prototype.

## Run it
- Open `Ladobc_Prototype.html` in a modern browser, or
- For GitHub Pages, upload `index.html` to the root of a repository and enable Pages from the `main` branch, `/ (root)`.

An internet connection is required because the prototype loads Three.js from jsDelivr.

## Current prototype contents
- Six selectable fighter entries: Colonel Sahab, Mauga Mogger, Pandit!!!, BHIMSHAKTI, PDFmaan, and Shantahdev.
- Basic 3D arena with placeholder geometric fighters.
- Player-versus-CPU combat, health bars, punch, kick, special attack, keyboard controls, and touch controls.

## Not included yet
This is not the finished game. Custom character likeness models, character-specific animated special-attack sequences, the supplied voice/music clips, polished animations, and online multiplayer are not implemented in this package.
